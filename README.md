# Swadeshi Server Fix 🇮🇳

**Gaon aur chhote shehron ke liye 2-minute me server/net problem solve karne wala web app**

---

## 🚨 Problem
Gaon me jab internet slow hota hai ya server down hota hai to logon ko:
- 2-2 ghante wait karna padta hai
- Sheher tak chakkar lagana padta hai  
- Kaam ruk jaata hai

## 💡 Solution
`Swadeshi Server Fix` ek simple web app hai jo bina technician ke problem batata hai aur step-by-step solution deta hai.

## ✨ Features
- **1-Click Diagnosis** - Net/Server problem 1 second me pata chale
- **Color Alerts** - Laal = Problem | Hara = Sab Thik
- **Step Guide** - Bina technical knowledge ke khud fix karo
- **Mobile Friendly** - Phone me bhi mast chalega
- **Popup Alert** - Button dabate hi solution aa jaye

## 🛠️ Tech Stack
**Frontend:** HTML5
